# Diretrizes para ferramentas

Antes de adicionar uma ferramenta ao repositório, documente:

- Problema que resolve e uso pretendido.
- Entradas, saídas e efeitos colaterais.
- Versão de Python e dependências necessárias.
- Exemplo com dados fictícios.
- Limitações, erros conhecidos e requisitos de autorização.

## Segurança e privacidade

Não inclua segredos, tokens, dados pessoais ou conjuntos de dados de terceiros. Evite operações destrutivas por padrão e deixe explícita qualquer alteração feita em arquivos. Ferramentas devem falhar de forma clara diante de entradas inválidas.
